I build gameplay systems in Unity — node graphs, simulation loops, and the
architecture that keeps them testable. Currently working on **LineForge**,
an idle/factory game shipping to Android, iOS and PC from a single codebase.

**What I'm focused on**

- Runtime node-graph architecture: interface-driven ports, dependency injection, no editor coupling
- UI Toolkit at production scale — design tokens, theming, safe-area handling across form factors
- Testable Unity code: Edit Mode tests over Play Mode, pure logic separated from MonoBehaviours
- CI/CD on self-hosted GitHub Actions runners with per-platform matrix builds

**Toolbox**

`C#` · `Unity` · `UI Toolkit` · `C++`  · `GitHub Actions` · `Docker`
